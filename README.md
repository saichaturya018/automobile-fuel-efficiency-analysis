🚗 Automobile Fuel Efficiency Analysis
A statistical data analysis project that investigates the relationship between vehicle characteristics and fuel efficiency using the Auto MPG dataset.

The project focuses on analyzing how factors such as vehicle weight, horsepower, engine displacement, and cylinders are associated with fuel efficiency (MPG). It uses Exploratory Data Analysis (EDA), descriptive statistics, correlation analysis, multivariate analysis, and statistical reasoning to explore the important concept of correlation vs causation.

🎯 Main Objective
To investigate whether heavier vehicles tend to have lower fuel efficiency and determine whether other factors, such as horsepower and engine displacement, may influence this relationship.

🔍 Key Analysis
Data cleaning and preprocessing

Descriptive statistical analysis

Exploratory Data Analysis (EDA)

Outlier and distribution analysis

Weight vs MPG correlation analysis

Multivariate analysis

Identification of potential confounding variables

Statistical interpretation of correlation vs causation

🛠️ Technologies Used
Python

Pandas

NumPy

Matplotlib

SciPy

Scikit-learn

📊 Dataset
Auto MPG Dataset containing vehicle characteristics such as MPG, cylinders, displacement, horsepower, weight, acceleration, model year, and origin.

🚀 Project Goal
The goal is not only to identify correlations but also to demonstrate that correlation alone does not prove causation. The analysis investigates whether the relationship between vehicle weight and fuel efficiency may be influenced by other related vehicle characteristics.
